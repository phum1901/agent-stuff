# Agent skills

A collection of skills for AI coding agents.

## Install

Install all skills:

```bash
npx skills add https://github.com/phum1901/agent-stuff
```

Install only the `discuss` skill:

```bash
npx skills add https://github.com/phum1901/agent-stuff --skill discuss
```

## Skills

- `discuss` - Turn rough ideas into clear implementation plans through focused questions.
